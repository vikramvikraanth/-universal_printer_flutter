Wire Format · Search & Receipt

What actually crosses:
search records & receipt line types

Every payload is a plain map encoded by Flutter's StandardMessageCodec. Enums travel as their Kotlin .name string. For a receipt, each element carries a "type" discriminator — that single field is what native Bridge.buildDocument switches on to rebuild the right PrintElement.

}

the two computed fields

resolved on the native side before crossing

isImpact — true when the model matches a 9-pin token (TM-U*, SP742…). Dart uses it to force PrintType.text and drop graphics.

effectiveEmulation — emulation ?? "ESC/POS". A bare port-9100 host reports ESC/POS rather than null, so the UI always has a language to show.

Unknown enum strings never throw: fromWire() falls back (brand → UNKNOWN, connectionType → network).

▤ Line types — Dart call → wire → native PrintElement
"text"Text line
darttext("HI", align: center, bold: true, invert: true, size: large)
wire{type:"text", text, align:"CENTER", bold, underline, invert, size:"LARGE"}
kt→ PrintElement.Text
"columns"Column row
dartcolumns([Column("Qty"), Column("Amt", weight:2, align:right)])
wire{type:"columns", cells:[{text, weight, align:"RIGHT"}]}
kt→ Columns(List<Column>)
"row"Two-column row
dartrow("Coffee", "3.50")
wire{type:"row", left, right, leftWeight, rightWeight}
kt→ Columns(left,right)
"imageUrl"Image by URLno-op on impact
dartimageUrl("https://…/logo.png", align: center)
wire{type:"imageUrl", url, align, invert, dither}
kt→ ImageUrl · Glide caches offline
"image"Raw bitmapbytes copy
dartimage(Uint8List bytes, align: center)
wire{type:"image", bytes:‹Uint8List›, align, invert, dither}
kt→ decodeByteArray → Image
"barcode"Barcode
dartbarcode("123…", symbology: ean13, heightDots: 100)
wire{type:"barcode", data, symbology:"EAN13", heightDots, align}
kt→ Barcode · ZXing renders
"qr"QR code
dartqr("https://…", sizeDots: 200, errorLevel: h)
wire{type:"qr", data, sizeDots, errorLevel:"H", align}
kt→ QrCode · ZXing renders
"feed"Line feed
dartfeed(2)
wire{type:"feed", lines: 2}
kt→ Feed(lines)
"divider"Divider rule
dartdivider()
wire{type:"divider"}
kt→ Divider
"raw"Raw ESC/POSescape hatch
dartraw(Uint8List escposBytes)
wire{type:"raw", bytes:‹Uint8List›}
kt→ Raw(bytes)

Native dispatch is one when(e["type"]) in Bridge.buildDocument — an unknown or missing type is skipped, not fatal. Impact printers run the document through textOnly() first, so imageUrl/image are dropped and barcode/qr collapse to their data text.
